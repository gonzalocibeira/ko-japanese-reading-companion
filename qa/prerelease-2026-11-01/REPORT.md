# Kō 1.4 pre-release pass — 1 November 2026

This is the pre-release snapshot taken before the owner requested GitHub publication.
The [1.4 release audit](../../docs/release-1.4-audit.md) records the subsequent stable
release preparation; statements about WIP and unpublished changes below describe
this earlier snapshot.

Three reproducible bugs were fixed. The final build passes all 276 automated tests,
type checking, and release-package validation. No publication or store submission
was performed; version 1.4 remains marked Unreleased (WIP).

## Bugs fixed

| Bug | Trigger and impact | Fix |
| --- | --- | --- |
| Empty Grammar results after loading in a hidden tool | Enter panel Grammar, leave before its index finishes loading, then return. The list remained empty until a filter changed. | Observe the list sentinel even when the initial load finishes while hidden. Showing Grammar starts its first batch and subsequent scrolling continues loading. |
| Lost keyboard focus when entering panel Grammar | Press ArrowRight from the Word forms tab. Grammar replaces the tab strip with a picker, but focus was sent to the hidden Grammar tab. | Focus the visible playground picker when the tab strip becomes hidden. |
| One online language lookup removed the other | Search for a Japanese term absent from bundled dictionaries, then choose an online language. Its result replaced both language controls, preventing the other lookup. | Give Japanese and English results independent sections so either lookup preserves the other control and result. |

The three regression tests failed against the original behavior and pass after the
fixes. The hidden-load regression also returns through keyboard navigation to cover
loading independently of input focus. Existing working-tree grammar-marker changes
were preserved.

Source changes: `src/playground-tools.ts` and `src/playground-browser.ts`.
Regressions: `tests/grammar-panel.spec.ts` and `tests/playground-v14.spec.ts`.
